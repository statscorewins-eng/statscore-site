Main Scoring Science

The official scoring science of STATS-CORE is:

Phoenix Multi-Sport Scoring Framework™

This framework governs how STATS-CORE produces one universal STATScore™ across multiple sports, positions, events, evidence types, verification levels, and intelligence domains.

---

Core Rule

There is:

One Universal STATScore™

There is NOT:

One universal formula for every sport and every position

Instead:

Each sport has its own scoring science.
Each position or event has its own matrix.
All outputs normalize into one explainable STATScore™.

Report Card Doctrine

The STATS-CORE Snapshot Report Card explains the combined STATS-CORE Snapshot Score.

It does not replace the Intelligence Centers.

It summarizes:

- Domain contribution
- Evidence strength
- Verification confidence
- Missing evidence
- Score drivers
- Score limiters
- Development priorities
- Recommended next actions

---

Dashboard Doctrine

The Athlete Dashboard is a Situation Report / Command Center.

It answers:

What is the athlete’s current state?

It does not explain every score.

Detailed explanations belong inside Intelligence Centers and the Report Card.

---

Engine Doctrine

Engines calculate.

Pages render.

Dashboards consume.

Reports explain.

Role dashboards display permissioned outputs.

No dashboard, profile, Crystal page, recruiter page, evaluator page, coach page, counselor page, parent page, or program page may independently calculate STATS-CORE scoring.
