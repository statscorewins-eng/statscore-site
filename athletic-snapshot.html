Athletic Signal Guide
Green — Strong / Verified / On Track

The current athletic signal is strong, confirmed, or aligned with the athlete’s position pathway.

Yellow — Developing / Partial / Needs Evidence

The athlete has usable indicators, but the system needs more evidence, better metrics, or verification.

Red — Missing / Weak / Requires Action

The athletic signal is missing, under target, or requires immediate correction to improve opportunity.
