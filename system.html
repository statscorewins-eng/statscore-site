Why This Layer Exists

Athlete Data Becomes Verified Intelligence.

STATScore is built for national use across Football, Basketball, Baseball, and Track & Field. The system separates self-reported information, coach-verified data, PHNX Verified evaluations, academic readiness, and media exposure so every athlete profile has a clear trust path.

System Position

Governed Access

Controlled Athlete Infrastructure

STATScore is not an open social platform. Athlete, parent, coach, counselor, recruiter, and organization access must be role-based, permissioned, and auditable.

Academic records, transcripts, communication windows, and recruiter access remain protected through visibility controls and parent/guardian permissions.

The athlete profile is visible. Sensitive academic and communication data is restricted.
